# cosmic-archive-v2 — أدلة حسية من أرشيفات أولية، مرتبة بزمن رحلة الإشارة

من أقدم ضوء (خلفية الميكروويف) إلى اليوم (الدماغ البشري، الشمس، الأرض، LHC)، بلا قفز:
كل حدث إما أن يكون له **ملف أولي موثّق**، أو يُكتب **سؤالاً مفتوحاً** بلا تعويض.

## ابدأ من هنا

| ملف | ماذا فيه |
|---|---|
| `INDEX.md` | الفهرس: جدول + بطاقة لكل حدث + عمودا **مصدر أولي (نعم/لا)** و**رصد/نموذج/اختبار** |
| `MANIFEST.csv` | صف لكل ملف: SHA-256، المجموع الرسمي ومقارنته، DOI وحلّه، الرخصة، الجهاز، معرّف البرنامج، تاريخ الرصد، المعالجة |
| `VERIFY_REPORT.md` | مُخرَج `verify.py` كما شُغّل (بما فيه الاختبار الذاتي) |
| `BLOCKED.md` | النطاقات المحجوبة في بيئة التنفيذ + الخطأ الحرفي + 3 طرق محاولة لكل نطاق |
| `LOG.md` | كل قرار اتُّخذ دون سؤال المستخدم |
| `FINAL.md` | سطر أول: رابط المشاركة على Google Drive |
| `fetch_primary.py` | المنزّل الكامل من الأرشيفات الرسمية (يعمل على أي جهاز أو Colab) |
| `tools/make_derived.py` | كل رسم/صوتنة معلنة مسبقاً — والمُدقِّقات البنيوية للصيغ |
| `tools/catalog.py` | المصدر الوحيد للحقيقة: الأحداث، الأجهزة، البرامج، الرخص، المنتجات، المدقّقات |
| `tools/make_index.py` · `verify.py` | بناء الفهرس والتحقق من الصفر |
| `_selftest/` | ملفات اصطناعية موسومة «اختبار» تُثبت أن السلسلة تعمل (ليست دليلاً) |
| `MANIFEST_NON_EVIDENCE.csv` | بصمات ملفات v1 المستبعدة وسبب استبعاد كل منها |

## التشغيل (جهاز عادي أو Colab)

```bash
pip install -r requirements.txt
python fetch_primary.py --all            # أو --event E02,E05 أو --dry-run
python tools/make_derived.py --all
python tools/make_index.py
python verify.py                         # يكتب VERIFY_REPORT.md
```

- `fetch_primary.py --dry-run` يطبع خطة التنزيل دون شبكة.
- `--force` يعيد التنزيل، `--refresh-license` يعيد حفظ نصّ الرخصة.
- `--jsoc-email you@x` يُفعّل تصدير JSOC لتسلسل AIA الأسرع (وإلا فVSO).

## قواعد المشروع (كما فُرضت)

1. **مصدر أولي فقط** — كل ملف من نطاق الأرشيف نفسه عبر واجهته (PLA/IRSA، GWOSC، MAST،
   SDO/JSOC-VSO، IRIS، CERN Open Data، OpenNeuro، أرشيف EHT). لا GitHub ولا دفاتر تعليمية.
2. **رصد فقط** — لا طيف نظري، لا ملف اختبار، لا قصاصة، لا هستوغرام جاهز. هذا ما استُبعد من v1.
3. **لكل ملف**: SHA-256 + مقارنة بالمجموع الرسمي إن نُشر + DOI يُحلّ + رخصة منصوصة من
   صفحة الأرشيف + تاريخ الرصد + الجهاز + معرّف البرنامج.
4. **كل معالجة ولون مُسند وتحويل صوتي مصرَّح به** في عنوان الشكل وفي `MANIFEST.csv`.
5. **ما لم يوجد يُكتب سؤالاً مفتوحاً** ولا يُعوَّض.

## حالة هذه النسخة

بيئة التنفيذ الحالية تحجب كل نطاقات الأرشيف (تفاصيلها في `BLOCKED.md`)، فنسخة التسليم
تحتوي المخطط + المنزّل + التحقق + الاختبار الذاتي، **بلا ملفات أولية**. الأحداث العشرة كلها
مكتوبة كأسئلة مفتوحة في `INDEX.md`، وشغّل `fetch_primary.py --all` في بيئة غير محجوبة
يملأ `raw/` تلقائياً ثم يُعيد `tools/make_index.py` و`verify.py` بناء كل شيء بالأرقام الحقيقية.
