# التاريخ الكامل للكون — النسخة العربية (PDF + مصدر LaTeX)

## ما في هذا المجلد

| الملف | الوصف |
|---|---|
| `book_ar.pdf` | الكتاب، ٥٥ صفحة، ٢٣ فصلاً، عربي بالكامل، من اليمين إلى اليسار، ١٨ صورة. |
| `main.tex` | مصدر LaTeX حقيقي (XeLaTeX + polyglossia/bidi + خطّ Amiri)، يطابق مضمون PDF. |
| `fonts/` | خطّا Amiri (Regular/Bold) — رخصة OFL. |
| `images/` | الصور الثماني عشرة كما نُزّلت من أرشيفات الجهات الأصلية. |
| `content_a.py … content_f.py` | نصوص الفصول والفقرات الإضافية (مصدر المحتوى). |
| `render.py` | مُصيِّر PDF العربي (ReportLab + arabic_reshaper + python-bidi). |
| `gen_tex.py` | مولّد `main.tex` من نفس المحتوى. |

## إعادة توليد PDF

```bash
pip install --break-system-packages reportlab arabic-reshaper python-bidi pymupdf
python3 render.py        # ينتج book_ar.pdf
python3 gen_tex.py       # ينتج main.tex
```

## إعادة التوليد بمحرّك LaTeX (على جهاز فيه TeX)

```bash
apt install texlive-xetex texlive-lang-arabic   # أو MacTeX
cd arabicbook
xelatex main.tex && xelatex main.tex
```

ملاحظة تقنية: الخطّ يُحمَّل بمسار نسبي `Path=fonts/`، فشغّل `xelatex` من داخل هذا المجلد.

## ملاحظات على المنهج

1. **الأرقام**: كل رقم في النص مأخوذ من النسخة الإنجليزية المنقّحة (٥٥ تصحيحاً)، ولم تُضف أرقام من خارجها إلا ما هو موثّق في مصادر أولية (بلانك ٢٠١٨، PDG، CODATA، نوبل).
2. **الأرقام العربية-الهندية**: حُوّلت الأرقام آلياً في المُصيِّر، مع استثناء الرموز اللاتينية (مثل `M87*` و`SN 1987A`).
3. **الأسس**: كُتبت بصيغة «١٠ أس سالب ٣٦» لتفادي مشكلة ترتيب ثنائي الاتجاه مع إشارة السالب، ولأن خطّ أميري لا يحتوي على محارف الأسس العلوية.
4. **الصور**: ١٨ صورة لـ٩ مواضيع (نسختان لكل موضوع). الأساسية داخل الفصول (١١ صورة)، والبقية في «ألبوم الصور» آخر الكتاب، فلم تُحذف صورة واحدة. بعض النسخ مصغّر (thumbnail) من الأصل، وقد أُدرج كما وُجد.
