# راصِـد | RASED — منظومة الإنذار المبكر والرصد الجيوسياسي والعسكري

منظومة متكاملة تجمع بين **تطبيق أندرويد أصيل (`APK`)** و**خادم سحابي دائم التأهب (`24/7 Cloud Sentinel`)** مدعوم بالذكاء الاصطناعي لرصد الحروب والتطورات الجيوسياسية والعسكرية عالميًا **من المصادر الأم فقط**، التحقق الصارم من الفيديوهات والنصوص، وإرسال إشعارات فورية وتفسيرات استراتيجية دقيقة بالعربية.

---

## المزايا الجوهرية

1. **بوابة المصادر الأم الصارمة (`Strict Root-Source Gatekeeper`)**:
   - الالتقاط الحصري من 16+ مصدرًا أمًا معتمدًا: وكالات الأنباء الدولية الأم (`Reuters`, `AP`, `AFP`, `BBC`, `Al Jazeera`)، هيئات الرقابة البحرية والنووية والأممية (`UKMTO`, `IAEA`, `UN Security Council`)، وزارات الدفاع والقيادات الرسمية (`Pentagon/CENTCOM`, `NATO`, `UK MoD`, `TASS`, `Xinhua`)، ومراكز الرصد العسكري (`SIPRI`, `ISW`, `Naval News`).
   - حجب تلقائي لمدونات التجميع الثانوية وحسابات الشائعات المجهولة ومقاطع الفيديو المعاد تدويرها.
2. **مصفوفة التحقق ومؤشر الدقة الرباعي (`0–100%`)**:
   - يحسب درجة الدقة بناءً على: أصالة المصدر الأم (`35%`)، التقاطع المستقل للمصادر (`30%`)، الاتساق الجغرافي والزمني (`20%`)، وسلامة الوسائط (`15%`).
3. **إعادة الصياغة العربية الرصينة والتفسير الجيوسياسي المعمّق**:
   - صياغة إخبارية عربية فصحى محايدة خالية من التهويل، مرفقة بمقتطف المصدر الأصلي، المنظومات العسكرية المعنية، ميزان الروايات المتقابلة، وسيناريوهات الـ `24–72` ساعة القادمة.
4. **مختبر الفحص الجنائي للفيديوهات والنصوص الحربية (`Video & Text Forensics Lab`)**:
   - استخراج إطارات الفيديو المرجعية، حساب البصمة الرقمية `SHA-256`، تحليل الطيف البصري (`NVG` الليلي، `FLIR` الحراري، ومضات الانفجار، القص الطولي لمنصات التواصل)، مع دعم الربط المباشر بـ **Google Gemini Multimodal** و**OpenAI GPT-4o Vision** و**Anthropic Claude**.
5. **تطبيق أندرويد `APK` بخدمة تأهب أمامية دائمة (`SentinelForegroundService.java`)**:
   - يعمل في خلفية هاتف الأندرويد على مدار الساعة (`START_STICKY` + `BootCompletedReceiver`) لإطلاق إشعارات عربية عالية الأولوية وصافرة تنبيه تكتيكية فور وقوع تطور عسكري مؤكد.

## طريقة استخراج وتحميل ملف `APK`

تم تجهيز مشروع أندرويد الكامل داخل مجلد `android/` وسير العمل السحابي التلقائي `.github/workflows/build-apk.yml`:
1. عند رفع الكود إلى GitHub (أو تشغيل Workflow يدويًا من تبويب **Actions** -> **Build Rased Android APK**)، يقوم GitHub تلقائيًا بتثبيت `JDK 21` و`Android SDK 36` وبناء التطبيق.
2. قم بتحميل الملف الجاهز `Rased-GeoIntel-APK.apk` من قسم **Artifacts** وثبّته مباشرة على هاتفك الأندرويد.
3. أو للبناء محليًا على جهاز يحتوي على Android SDK:
   ```bash
   npm run build:apk
   ```

