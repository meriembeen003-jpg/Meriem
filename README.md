# مِرصد — تصريحات من المصادر الأصلية

تطبيق Android/ويب عربي لمتابعة المواد المنشورة علنًا من جهات رسمية ومؤسسات عامة. على Android، يقرأ التطبيق الخلاصات باستخدام طلبات HTTP أصلية من Capacitor، ويعرض الرابط والناشر واللغة والتاريخ كما وردت في المصدر؛ لا ينشئ اقتباسات أو ملخصات مولّدة.

## المصادر المدمجة

- البوابة الرسمية للمغرب — صفحة الأخبار العربية.
- GOV.UK — خلاصة Atom للأخبار والبيانات الحكومية.
- موقع الحكومة الفرنسية — خلاصة RSS.
- البيت الأبيض — خلاصة RSS.
- UN News — مصدر أممي منفصل بوضوح عن البيانات الحكومية الوطنية.

تُظهر الواجهة حالة كل مصدر، وعند تعذّر الوصول لا تستبدل المحتوى ببيانات تجريبية أو مخمّنة. الخلاصات الخارجية تحتاج اتصال إنترنت؛ قد تمنع بعض المتصفحات وصول الويب بسبب CORS، بينما يستخدم تطبيق Android طلب HTTP أصليًا. كل مادة تفتح الصفحة الأصلية للجهة.

## الخصائص

- واجهة RTL مصممة للهاتف أولًا، مع نشرة قابلة للبحث والتصفية حسب البلد.
- قراءة صوتية على الجهاز للعناوين والمقتطفات، وحفظ المواد وكتابة ملاحظات محلية.
- روابط بث عام إلى صفحات الناشر، من دون إعادة استضافة البث.
- لا حساب ولا رفع تلقائي للملاحظات؛ الحفظ محلي على الجهاز.

> مِرصد لا يلتقط ترددات الراديو، ولا يعترض اتصالات خاصة أو مشفّرة، ولا يعمل كنظام إنذار. المصدر الأولي يثبت ما نشرته الجهة، لا صحة كل ما ورد فيه.

## التشغيل والبناء

```bash
npm ci
npm run dev
npm run lint
npm run build:android
cd android && ./gradlew assembleDebug
```

يُنتج CI ملف APK تجريبيًا قابلًا للتثبيت كـ artifact باسم `marsad-debug-apk`. نسخة debug مخصّصة للاختبار وليست إصدارًا موقّعًا للنشر على Google Play.
