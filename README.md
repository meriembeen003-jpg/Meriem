# مِرصد — من المصدر، لا من الصدى

تطبيق ويب عربي قابل للتثبيت لمتابعة مصادر عامة أولية، وقراءة موجز زلزالي مفتوح من USGS، وتسجيل ملاحظات التحقق محليًا.

## ما الذي يفعله؟

- واجهة عربية RTL متجاوبة للهاتف والحاسوب.
- مكتبة روابط مباشرة لمصادر عامة؛ تُفتح المادة الأصلية بدل نسخها أو تقديمها كتأكيد للحقيقة.
- موجز زلازل من خدمة USGS العامة، مع رابط وتوقيت لكل حدث، وتوضيح عند فشل الاتصال بدل عرض بيانات قديمة كأنها حيّة.
- دفتر ملاحظات محلي، وتصدير نسخة احتياطية بصيغة JSON.
- Manifest وService Worker لدعم التثبيت كتطبيق ويب (PWA) والتخزين الأساسي للعمل دون اتصال.

> لا يلتقط التطبيق ترددات الراديو، ولا يعترض اتصالات خاصة أو محمية، ولا يعمل كنظام إنذار رسمي. المصدر الأولي يثبت ما نشرته الجهة، لا صحة كل مضمون بالضرورة.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## التحقق والبناء

```bash
npm run lint
npm run build
```

تتضمن الشيفرة غلاف Android أصليًا عبر Capacitor. استخدم `npm run build:android` لتصدير الواجهة ومزامنتها مع مشروع Android، ثم `cd android && ./gradlew assembleDebug` لإنتاج APK تجريبي. عند النشر للمستخدمين، يلزم إنشاء APK إصدار وتوقيعه بمفتاح خاص؛ لا تحفظ مفاتيح التوقيع في المستودع.

بناء CI ينشئ APK تجريبيًا قابلًا للتثبيت كـ artifact باسم `marsad-debug-apk`.
