# مِرصد 3.0.0 — قارئ المصادر الأولية

تطبيق Android وويب عربي لمتابعة ما تنشره جهات عامة على مواقعها الرسمية. يعرض العنوان والمقتطف والناشر واللغة وتاريخ النشر المتاح، ويربط مباشرة بالنص الكامل لدى الناشر. لا يختلق الأخبار ولا يقدّم النشر الرسمي بوصفه تحققًا مستقلًا من الادعاءات.

## الاستخدام

- النشرة تدعم البحث والتصفية حسب المصدر، مع إظهار حالة كل خلاصة بدل إخفاء فشل الاتصال.
- يمكن إضافة حتى 20 خلاصة RSS أو Atom عبر HTTPS من شاشة «مصادر الرصد». افحص نطاق الناشر بنفسك قبل الاشتراك؛ التطبيق لا يوثّق المصدر المخصص نيابةً عنك. تُحفظ قائمة المصادر على الجهاز.
- المحفوظات والملاحظات متاحتان من شريط التنقل السفلي، وتُخزّنان محليًا.
- عند فتح التطبيق دون اتصال، يمكن قراءة آخر خلاصات جرى جلبها مع تمييزها بوضوح كبيانات قديمة.
- القراءة الصوتية تستخدم محرّك الجهاز، وقد تعتمد اللغة والصوت المتاحان على إعداداته.

## المصادر المدمجة

- البوابة الرسمية للمغرب — صفحة الأخبار العربية.
- GOV.UK — خلاصة Atom للأخبار والبيانات الحكومية.
- الحكومة الفرنسية — خلاصة RSS.
- البيت الأبيض — خلاصة RSS.
- UN News — مؤسسة دولية، وليست حكومة وطنية.

تحتاج الخلاصات إلى اتصال بالإنترنت. قد تمنع قيود CORS جلب بعضها من المتصفح؛ يستخدم تطبيق Android طلبات Capacitor الأصلية. حالة الاتصال تعكس نجاح جلب الخلاصة وقت الفحص فقط، لا اكتمال مواد الجهة أو موثوقية محتواها.

> مِرصد لا يلتقط ترددات الراديو ولا يعترض اتصالات خاصة أو مشفّرة، وليس نظامًا للطوارئ. المادة المنشورة تثبت ما نشرته الجهة ولا تثبت وحدها صحة الادعاء.

## التطوير والبناء

```bash
npm ci
npm run dev
npm run lint
npm run build:android
cd android && ./gradlew assembleDebug
```

يبني CI ملف APK تجريبيًا باسم `marsad-debug-apk`. نسخة Debug للاختبار وليست موقعة للنشر على Google Play.
